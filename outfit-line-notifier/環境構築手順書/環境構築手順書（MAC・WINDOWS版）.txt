================================================================
  outfit-line-notifier 環境構築手順書（Mac / Windows 共通）
================================================================

----------------------------------------------------------------
【事前準備】LINE Messaging API の設定
----------------------------------------------------------------

1. https://developers.line.biz/ja/ にアクセスしてログイン

2. プロバイダーを作成
   - 「プロバイダーを作成」をクリック
   - 任意の名前を入力（例: 個人用）

3. チャネルを作成
   - 「チャネルを作成」→「Messaging API」を選択
   - チャネル名・説明・大業種・小業種を入力して作成

4. チャネルアクセストークンを発行
   - チャネル →「Messaging API設定」タブを開く
   - 一番下の「チャネルアクセストークン（長期）」→「発行」をクリック
   - 表示された文字列（約170文字）をメモしておく

5. 自分のユーザーIDを確認
   - 同じページのQRコードをスマホのLINEで読み取り、Botを友だち追加
   - チャネル →「チャネル基本設定」タブを開く
   - 「あなたのユーザーID」（U から始まる文字列）をメモしておく

----------------------------------------------------------------
【1】Ollama のインストール
----------------------------------------------------------------

■ Windows
  1. https://ollama.com/download/windows を開く
  2. OllamaSetup.exe をダウンロードして実行
  3. インストール完了後、タスクトレイに Ollama アイコンが表示される

■ Mac
  1. https://ollama.com/download/mac を開く
  2. Ollama-darwin.zip をダウンロードして展開
  3. Ollama.app をアプリケーションフォルダに移動して起動

----------------------------------------------------------------
【2】モデルの取得
----------------------------------------------------------------

ターミナル（Mac）またはコマンドプロンプト / PowerShell（Windows）で実行：

  ollama pull qwen2.5

※ 約5GB のダウンロードが発生します。完了まで数分かかります。

----------------------------------------------------------------
【3】プロジェクトのセットアップ
----------------------------------------------------------------

■ Windows（PowerShell）

  cd outfit-line-notifier
  python -m venv .venv
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
  .venv\Scripts\Activate.ps1
  pip install -r requirements.txt

■ Mac / Linux（ターミナル）

  cd outfit-line-notifier
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt

----------------------------------------------------------------
【4】config.py の設定
----------------------------------------------------------------

config.py を開き、以下の項目を設定してください。

  ┌─────────────────────────────────────────────────────────────┐
  │ class UserConfig                                            │
  │   NAME            自分の名前                               │
  │   GENDER          "male" または "female"                   │
  │   AGE             年齢                                      │
  │   HEIGHT_CM       身長（cm）                               │
  │   STYLE_PREFERENCE 好みのスタイル                          │
  │   NG_ITEMS        避けたいアイテム（リスト形式）           │
  │   FAVORITE_COLORS 好きな色（リスト形式）                   │
  │                                                             │
  │ class LocationConfig                                        │
  │   LOCATION_NAME   地域名（例: 名古屋市栄）                 │
  │   LATITUDE        緯度（Google マップで確認可能）          │
  │   LONGITUDE       経度（Google マップで確認可能）          │
  │                                                             │
  │ class LineConfig                                            │
  │   CHANNEL_ACCESS_TOKEN  手順【事前準備】4 で取得したトークン│
  │   USER_ID               手順【事前準備】5 で確認したID     │
  │                                                             │
  │ class AppConfig                                             │
  │   NOTIFY_HOUR     通知時刻（時）デフォルト: 7              │
  │   NOTIFY_MINUTE   通知時刻（分）デフォルト: 0              │
  │   OLLAMA_MODEL    使用モデル デフォルト: "qwen2.5"         │
  └─────────────────────────────────────────────────────────────┘

※ 場所の緯度・経度は Google マップで地名を検索し、
  URLの「@35.167,136.907」のような部分から確認できます。

----------------------------------------------------------------
【5】動作確認（手動実行）
----------------------------------------------------------------

■ Windows
  .venv\Scripts\Activate.ps1
  python main.py --run-now

■ Mac
  source .venv/bin/activate
  python main.py --run-now

LINEにコーデ通知が届けばセットアップ完了です。

----------------------------------------------------------------
【6】通常起動（毎朝7時の自動通知）
----------------------------------------------------------------

■ Windows
  python main.py

■ Mac
  python main.py

起動したまま PC をスリープさせないようにしてください。
Flaskサーバーが http://127.0.0.1:5000 で起動します。

API経由での手動実行も可能です：
  curl -X POST http://127.0.0.1:5000/run-now

----------------------------------------------------------------
【エラー対応】
----------------------------------------------------------------

  エラー内容                       確認事項
  ─────────────────────────────────────────────────────────────
  天気情報の取得に失敗              インターネット接続を確認
  Ollamaに接続できません            ollama serve が起動中か確認
  LINE通知失敗 (401)               CHANNEL_ACCESS_TOKEN を再確認
  LINE通知失敗 (400)               USER_ID の形式を確認（U始まり）
